# Podugu Jyoshna Priya — Personal Portfolio

A responsive, accessible personal portfolio created for the Full Stack Development (SPC0701CS) Assignment-1 requirements.

## Stack
- HTML5 semantic structure
- CSS3, Flexbox/Grid, media queries
- Bootstrap 5.3.3
- Bootstrap Icons
- JavaScript (ES6+)

## Features
- Responsive mobile-first layout
- Semantic Home, About, Education, Skills, Projects, Experience, Certifications, Achievements, Contact and Footer sections
- Bootstrap navbar, grid, cards, buttons and form controls
- Dark/light theme switching with localStorage
- Project filtering
- Client-side contact-form validation with dynamic messages
- Accessible labels, focus states, status messaging and responsive navigation
- Smooth scrolling and subtle hover interactions

## Run locally
1. Download/clone this repository.
2. Keep the folder structure unchanged.
3. Open `index.html` in a modern browser, or serve the folder with a simple local server.

Example with VS Code: install Live Server and open `index.html` with Live Server.

## GitHub + Vercel deployment
### GitHub
1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Commit and push the project.
4. Use the repository URL as the assignment submission URL.

### Vercel
1. Sign in to Vercel with GitHub.
2. Import the portfolio repository.
3. For this static site, no build command is required.
4. Set the output/root directory to the repository root if prompted.
5. Deploy.

Note: the assignment says GitHub Pages/live deployment is optional; the GitHub repository is required.
